THE QUESTION BEHIND THE CHARTS

What changes when we look beyond the total?

Total case counts show volume, but they do not account for population size. Comparing recent cases, deaths, and rates per 100,000 adds context to the story.

03 / DATA NOTES

About this project

A

Dataset

Source file: US_Covid.xlsx. The workbook contains 50 state records and five fields.

B

Measures

Total cases, total deaths, cases in the last seven days, and rate per 100,000.

C

Interpretation

Totals and population-adjusted rates answer different questions. Avoid treating them as interchangeable.

D

Time context

The supplied workbook does not identify a reporting date or date range. Add that information when confirmed from the original source.
